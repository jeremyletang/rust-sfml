# AGENTS.md — `src/ffi/`

Raw `extern "C"` declarations for the CSFML shim. Private to the crate. The `*_bindgen.rs` files are generated by `rust-sfml-bindgen` and must not be edited by hand or by any tool. The hand-written files hold the FFI-only types they depend on.

## Hand-written

- `system.rs`: `sfTime`, `sfBuffer` alias, input stream callback types, and opaque system types, including the private `sfString` handle with its `Drop` impl. Includes `system_bindgen.rs`.
- `window.rs`: window enums (keys, scancodes, mouse buttons, joystick axes, sensor types, cursor types), event structs and union, `sfContextSettings`, the per-OS `sfWindowHandle`, and the Vulkan handle types (`VkInstanceT`, `VkInstance`, `VkSurfaceKHR`, `VkAllocationCallbacks`). Includes `window_bindgen.rs`.
- `graphics.rs`: opaque graphics types, blend and stencil enums, shader and font types, vertex and GLSL structs, primitive types, and the text glyph callback type. Includes `graphics_bindgen.rs`.
- `audio.rs`: opaque audio types, `sfSoundStreamChunk`, `sfTimeSpan`, cone converters for listener and sound source, effect processor trampoline, and recorder and stream callback types. Includes `audio_bindgen.rs`.

## Generated (do not edit, do not run rustfmt on)

The `*_bindgen.rs` files must not be formatted with rustfmt. Don't run `rustfmt` or `cargo fmt` on them, and don't include them in any formatting pass. They are regenerated by the tool, so formatting them only creates diffs that get overwritten.

- `system_bindgen.rs`: Buffer, Clock, InputStreamHelper, SfStdString, SfStdVector, SfString, Sleep, Version.
- `window_bindgen.rs`: Clipboard, Context, Cursor, Joystick, Keyboard, Mouse, Sensor, VideoMode, Window, Vulkan.
- `graphics_bindgen.rs`: CircleShape, ConvexShape, CustomShape, Font, Image, RectangleShape, RenderTexture, RenderWindow, Shader, Sprite, Text, Texture, Transform, VertexBuffer, View.
- `audio_bindgen.rs`: CustomSoundRecorder, CustomSoundStream, Listener, Music, PlaybackDevice, Sound, SoundBuffer, SoundBufferRecorder, SoundChannel, SoundRecorder.
